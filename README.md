# Onam
'ओनम' (Onam) एक ऑल-इन-वन सोशल मीडिया प्लेटफॉर्म है, जो ट्विटर (फ़ीड), इंस्टाग्राम (रील्स), फ़ेसबुक (पोस्ट) और व्हाट्सएप (डायरेक्ट चैट) को एक साथ जोड़ता है। इसमें ₹1 के भुगतान पर 'लाइफटाइम ब्लू टिक' और आधार OTP वेरिफिकेशन से 'Aadhaar Verified' बैज मिलता है। यह स्पैम-मुक्त और पूरी तरह सुरक्षित सोशल नेटवर्क प्रदान करता है।
